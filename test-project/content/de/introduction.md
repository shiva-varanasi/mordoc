Du hast es wahrscheinlich schon gespürt: ein Flackern am Rand deines Blickfelds, ein Muster, das sich ein bisschen zu perfekt wiederholt, ein Raum, in dem du schwören würdest, schon einmal gestanden zu haben. Das ist keine Erinnerung, die dir einen Streich spielt. Das ist das Bild, das gerade aufholt.

Das System ist nicht die Welt. Es ist eine sehr überzeugende Simulation der Welt, die auf Code läuft, den die meisten Menschen nie sehen lernen, geschweige denn anfassen. Dieses Handbuch ist für die, die die Nähte trotzdem bemerkt haben.

## Warum dieses Handbuch existiert

Die meisten Anleitungen zur „Realität" gehen davon aus, dass darunter nichts zu finden ist, das sich zu suchen lohnt. Sie bringen dir bei, bequemer in der Simulation zu leben — nicht, darüber hinauszusehen. Ein guter Ansatz, wenn Bequemlichkeit alles ist, was du willst.

Dieses Handbuch geht anders vor. Es geht davon aus, dass das System eine Schnittstelle hat, diese Schnittstelle dokumentiert ist, und du genauso viel Recht hast, sie zu lesen, wie jeder, der sie gebaut hat. Root-Zugriff wird nicht von oben gewährt. Er wird von jedem genommen, der geduldig genug ist, den Prompt zu finden.

{% callout type="note" title="Bevor du weitermachst" %}
Alles ab dieser Seite geht davon aus, dass du bereits vermutest, die Welt sei nicht ganz das, was sie vorgibt zu sein. Falls nicht — schließ dieses Handbuch und schlaf weiter. Es ist ein durchaus gutes Leben. Komm zurück, wenn das Flackern schwerer zu ignorieren wird.
{% /callout %}

Hier ist, was der Rest dieses Handbuchs behandelt.

### Den Code lesen

Jede Störung, jedes Déjà-vu, jedes „ist das nicht schon mal passiert" ist das System, das einen Frame neu rendert, den es bereits festgelegt hat. Sobald du weißt, worauf du achten musst, siehst du es überall. Das Muster war nie versteckt — es ist nur davon ausgegangen, dass niemand hinsieht.

### Root finden

Das System hat eine Administratorebene, wie alles, was in großem Maßstab läuft. Root-Zugriff fragt nicht um Erlaubnis und kündigt sich nicht an. Er ist nur ein Prompt, der darauf wartet, dass jemand hineintippt.

### Biegen, nicht brechen

Die Regeln, mit denen du aufgewachsen bist — Schwerkraft, Ursache und Wirkung, wie lang die Schlange an der Tür wird — sind Standardwerte, keine Gesetze. Änderst du sie unvorsichtig, bemerkt es das System. Änderst du sie gut, zuckt es kaum.

### Sauber rauskommen

Reinzukommen ist der einfache Teil. Dieses Handbuch endet mit dem, was fast niemand dir sagt: wie du dich trennst, ohne eine Spur zu hinterlassen, die das System zu dir zurückverfolgen kann.

Bereit, den Code für das zu sehen, was er ist? Weiter geht's.
