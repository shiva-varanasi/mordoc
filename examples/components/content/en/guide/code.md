Code blocks show code with highlighting and a copy button.

## JavaScript

```js
const stops = ['Stop A', 'Stop B', 'Stop C'];
console.log(stops.length);
```

## TypeScript

```ts
interface Stop {
  name: string;
  daysOnFoot: number;
}
```

```bash
journey plan stop-a stop-d
cd my-journey
```

```json
{ "name": "Stop B", "daysOnFoot": 40 }
```

## YAML

```yaml
stop: Stop C

```
