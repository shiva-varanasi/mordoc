---
title: Callouts
---

A callout highlights a short message. There are four types, each with or without a title.

## With a title

{% callout type="note" title="Note" %}
The guide saves your route every evening.
{% /callout %}

{% callout type="tip" title="Tip" %}
Rest in Rivendell before you cross the mountains.
{% /callout %}

{% callout type="warning" title="Warning" %}
The mountain pass closes when the first snow falls.
{% /callout %}

{% callout type="danger" title="Danger" %}
Never enter Mordor without a guide.
{% /callout %}

## Without a title

{% callout %}
A callout without a type is a note.
{% /callout %}

{% callout type="tip" %}
A tip without a title.
{% /callout %}

{% callout type="warning" %}
A warning without a title.
{% /callout %}

{% callout type="danger" %}
A danger without a title.
{% /callout %}

## With other content

{% callout type="note" title="Before you leave" %}
- Pack food for the road.
- Plan your route.

```bash
journey plan the-shire mordor
```

> Every journey starts at your own front door.
{% /callout %}
