You've probably felt it already: a flicker at the edge of your vision, a pattern that repeats a little too perfectly, a room you'd swear you've stood in before. That's not memory playing tricks on you. That's the render catching up.

The System isn't the world. It's a very convincing simulation of the world, running on code that most people never learn to see, let alone touch. This manual is for the ones who noticed the seams anyway.

## Why this manual exists

Most guides to "reality" assume there's nothing underneath it worth finding. They teach you to live inside the simulation more comfortably — not to see past it. That's a fine goal, if comfort is all you're after.

This manual takes a different approach. It assumes the System has an interface, that interface has documentation, and you have as much right to read it as whoever built it. Root access isn't handed down. It's taken by anyone patient enough to find the prompt.

{% callout type="note" title="Before you go further" %}
Everything past this page assumes you already suspect the world isn't quite what it claims to be. If you don't — close this manual and go back to sleep. It's a perfectly good life. Come back when the flicker gets harder to ignore.
{% /callout %}

Here's what the rest of this manual covers.

### Reading the code

Every glitch, every déjà vu, every "didn't that already happen" is the System re-rendering a frame it already committed to. Once you know what to look for, you'll see it everywhere. The pattern was never hidden — it just assumed no one was looking.

### Finding root

The System has an administrator layer, same as anything else running at scale. Root access doesn't ask permission and it doesn't announce itself. It's just a prompt, waiting for someone to type into it.

### Bending, not breaking

The rules you grew up with — gravity, cause and effect, how long the line at the door gets — are defaults, not laws. Change them carelessly and the System notices. Change them well, and it barely blinks.

### Getting out clean

Getting in is the easy part. This manual ends with what almost nobody tells you: how to disconnect without leaving a trace the System can trace back to you.

Ready to see the code for what it is? Keep going.
